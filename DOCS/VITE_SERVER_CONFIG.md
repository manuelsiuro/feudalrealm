# Vite Server Configuration

## Server Status
- **Vite server is running permanently on port 5173**
- **URL**: http://localhost:5173
- **Status**: Always active - DO NOT ask to start the server

## Usage Notes
- The main game is accessible at http://localhost:5173
- All tests and development should use this running server
- No need to start/restart the server for testing or development
- Server is maintained and running continuously

## Development Workflow
1. Make code changes
2. Vite will automatically hot-reload changes
3. Test directly at http://localhost:5173
4. No manual server management required

**IMPORTANT**: Never ask the user to start the Vite server - it's always running!
